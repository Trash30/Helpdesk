Login process

  1. Enter your email address and password provided by the administrator
  2. Click Login — the session lasts 8 hours then expires automatically
  3. First access: a password change is required before accessing the application
The password must contain at least 8 characters, one uppercase letter and one digit. A strength indicator is displayed as you type.

Forgotten password

Click "Forgot password?" → enter the email address → a reset link is sent by email (valid for 24h, single use).

Logout

Click the avatar at the top left of the sidebar → Log out.

Internal notes

The "Internal note" toggle in the comment area (yellow background) makes the comment visible only to agents — never to clients.

Create a knowledge base article from a closed ticket

After closing, if you have the kb.write permission, a dialog offers to create a pre-filled KB article with the ticket's title and comments. Useful for capturing resolutions for future reference.

Shortcuts: Ctrl+Enter to send a comment · Ctrl+B bold · Ctrl+I italic · Ctrl+` code

Available sub-menus

SectionFeatures
TeamCreate, edit, activate/deactivate agent accounts. Send a password reset email (link valid for 24h).
RolesCreate custom roles and configure the 23 available permissions. A permission change takes effect immediately on all active sessions.
CategoriesManage ticket categories (name, colour). Reorderable by drag and drop.
OrganisationsSports federations and leagues (e.g. LNR, LNH). Parent hierarchy of clubs.
ClubsSports clubs attached to an organisation (e.g. PSG Handball, Stade Toulousain).
DivisionsInternal VOGO support divisions (e.g. Production, Technical, Commercial).
Ticket typesTicket sub-categories (e.g. Incident, Request, Question).
SurveysCSAT and NPS scores from surveys sent automatically after a ticket is closed.
SettingsCompany logo, display name, default priority, automatic closing (N days), survey delay and cooldown.
The client hierarchy is: Organisation (e.g. LNH) → Club (e.g. PSG Handball) → Contact (e.g. Jean Martin). This structure allows tickets to be filtered by organisation or club from the ticket list.
